# CPET_253_Final_project
This Will be the database to store all the code for my final project in Micro-controller systems class at Rochester Institue of Technology.
This code will be used to control the Garmin Lidar Lite V3 using a MSP432 micro-controller.

This project will include the use of bluetooth module on the msp432 and lcd display, leds and the lidar sensor and interrupts.

LIDAR stands for "Light Detection and Ranging" which uses lasers pulses to create a map of the enviroment. It calculates the distance via the time it 
takes for the laser to hit the object then to bounce back and get recieved by the sensor. It is commonly used in aviation or terrestrial scanning. 

This project will Adheer to all licensing that Garmin has set forward.
